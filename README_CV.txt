MOHAMED'S RESUME / CV INSTRUCTIONS
=====================================================

To connect your actual CV / Resume:
1. Save your CV file as a PDF named "Mohamed_CV.pdf"
2. Place it right here in this folder:
   assets/cv/Mohamed_CV.pdf

Once placed, the "Download CV" buttons in the Hero section
and Navigation bar will immediately download your file.

If no file is found yet, the website gracefully shows a 
helpful popup message to recruiters notifying them that your 
updated CV is available upon request via email or LinkedIn.
